# cph4-hy-scanner

微信文档扫描小程序。拍摄、裁切、图像编辑和多页 PDF 导出在手机上完成。配置 VPS 后，可在同一个小程序内对当前页执行文字识别、图像修复和文档识别。

## 项目结构

- `miniprogram/` 微信原生小程序和 TypeScript 图像处理。
- `server/` FastAPI 单页图像处理、文字识别和可选多模态识别服务。
- `docs/` 微信预览和真机验收说明。

## 开发检查

```sh
npm ci
npm run typecheck
npm test
npm run build
```

构建产物在 `dist/miniprogram/`。GitHub Actions 可生成手机预览。[微信预览说明](docs/wechat-preview.md) · [服务端配置](server/README.md) · [真机验收](docs/p0-acceptance.md)

## 本地编辑和导出

- 在「文档增强」中将锐化设为「轻度」或「强力」，增强可辨认的笔画边缘。
- 在「马赛克与水印」中为当前页框选马赛克区域。水印可输入文字或从相册选图片，两种来源均可单个摆放或全页平铺，可调整大小、透明度和角度。保存 JPG 或导出 PDF 时会将这些编辑渲染到输出文件。
- 在扫描转 PDF 的导出界面点「手写签名」，写好后拖动签名定位。签名作为可见笔迹写入生成的 PDF。
- 在首页点「签署已有 PDF」，从聊天选择 10 MB 以内、最多 50 页的文件。用「查看原 PDF」对照内容，在页面位置示意图中放置手写签名，再生成签名副本。

## 当前页文字识别

在扫描界面选择一页，在「文字识别」区域点击「识别第 N 页」，再确认「上传识别」。结果会显示在同一区域，可点击「复制文字」。首批支持简体中文和英文印刷文字。

此功能需要在小程序中配置 VPS，并在 VPS 上安装 Tesseract 和对应语言包。确认后只上传当前页。[服务端配置](server/README.md)

## VPS 文档工具

在扫描页选中一页，从「页面工具」进入「智能工具」。选择所需功能，预览当前页后点击「处理当前页」并确认上传。

| 功能 | 使用方式和结果 |
| --- | --- |
| 票据、证件识别 | 提取当前页可见字段，核对标注为不确定的内容。 |
| 识别错题 | 提取当前页可见的题目、作答和可辨认的批改依据，方便对照原页核对。 |
| 试卷擦除 | 减弱红蓝色手写和批改笔迹。彩色印刷内容可能受影响，黑色手写和完全遮挡的原字无法可靠分离。 |
| 模糊字迹修复 | 加强可见的边缘和笔画对比度。严重失焦导致的缺失细节无法可靠恢复。 |

图像处理结果可切换查看处理前后，另存图片或在界面允许时应用到扫描页。

票据、证件和试卷识别需要支持图片输入的 OpenAI 兼容 Chat Completions 模型。部署时在 VPS 填写 `SCANNER_AI_BASE_URL`、`SCANNER_AI_API_KEY` 和 `SCANNER_AI_MODEL`，三个变量默认为空。确认上传后，VPS 会将当前页发送给所配置的模型服务。图像修复在 VPS 自身运行。[多模态配置](server/README.md)

## 交付顺序

1. 继续在微信真机验收扫描、图像编辑、PDF 导出和签名。
2. 在目标 2 核 2 GB VPS 验证文档识别和修复的结果及资源占用。
3. 后续开发证件照制作和按原版式重建可编辑 Word。
