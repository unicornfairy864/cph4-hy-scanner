# 试卷黑笔擦除验收

## 当前验证状态

工作区的服务端自动测试有 40 项通过，1 项 OCR 测试因缺少简体中文训练数据 `chi_sim` 跳过。客户端 TypeScript 本地测试有 36 项通过。另用合成试卷走通客户端裁切、旋转、马赛克、普通候选和显式擦除，模拟微信请求核对了 AI 上传确认、候选状态、尺寸校验和取消后的文件回收。

合成测试确认算法处理后的像素数组在擦除区域之外保持一致。JPEG 重新编码可带来轻微压缩差异，真机验收以印刷细节仍可辨认为准。

目标 2 核 2 GB VPS 的资源占用、真实 DeepSeek 返回的框、iOS 和安卓微信的触摸与导出仍待验收。记录构建提交、手机型号、系统和微信版本、网络、VPS 规格与模型标识。[微信预览说明](wechat-preview.md) · [黑笔擦除部署](black-ink-deployment.md)

## 手机样张

准备可公开用于测试的练习纸。用虚构编号替代姓名、学校和证件号。

- **裁切与旋转。** 在印有几行题干的练习纸右上空白画一个粗黑勾，左下写虚构编号。斜拍后裁边，顺时针旋转 90°，对编号添加马赛克。黑勾应出现在旋转后页面的右下区域。
- **手写与印刷相邻。** 在空白处写黑字，再加一笔压过一行印刷字。保留题号、细标点、公式中的正负号和一小段红蓝批改，供前后对照。
- **对照页。** 拍一张只有印刷题干、表格和图形的纸，另拍一张印刷文字已被一笔完全覆盖的纸。多页测试时，把它们放在需要擦除的页面前后。

## 逐项核对

在扫描页选中样张，经「页面工具」→「智能工具」→「试卷擦除」→「标记擦除黑笔」进入编辑器。在 iOS 和安卓微信上分别执行，给每项记录通过、失败或待测。

| 检查 | 通过条件 |
| --- | --- |
| ☐ 手动圈选与画笔 | 打开编辑器、圈选、移动或调大小、画擦除笔或保护笔、缩放、撤销时保持本地操作。点击「生成擦除预览」后出现本次 VPS 上传确认，拒绝时保留编辑并取消上传。 |
| ☐ 普通候选授权 | 点击「VPS 提示」后先确认。只提交当前页到项目 VPS。返回框显示「待核对」或「需重点核对」，原图像素保持原样。 |
| ☐ DeepSeek 授权 | 点击「DeepSeek 提示」后单独确认，界面说明当前页经 VPS 转给已配置的视觉服务。拒绝时保留本地编辑。未配置、无候选、返回异常或模型超时时，可继续使用普通候选或手动工具。 |
| ☐ 逐框审核 | 移动或调大小后再决定采用、忽略或撤销。只靠待核对或已忽略的框无法发起擦除。标为「需重点核对」的框逐个与题干和图形比对。点击「生成擦除预览」后，已采用的框仍只清理可区分的笔迹。 |
| ☐ 可分离笔迹与保护优先 | 空白中的黑笔可清理。框内发现难以区分的笔迹时，可放大，用细擦除笔和保护笔调整。让两种笔刷重叠，保护笔划过的题干、标点和公式应保留。 |
| ☐ 方向与马赛克 | 裁切、旋转或放大平移后，框和画笔仍落在当前图的对应位置。编辑器「原图」、普通候选输入、AI 输入和擦除预览均保留原有马赛克。受保护页走「保存图片」，扫描页保留当前保护设置。 |
| ☐ 空页和完全遮挡 | 空白测试纸应返回空候选并保持原样。仅有印刷内容的对照页应保留全部可见印刷，误框记录后忽略。完全被黑笔挡住的原字按不可恢复记录，预览中不得出现猜测填出的文字或答案。同版空白模板复原留到后续版本单独验收。 |
| ☐ 取消、超时与返回 | 上传或排队时取消，或断网、返回上一页、模拟服务超时，再重新打开编辑器。旧响应不得覆盖当前页或新的预览，扫描和本地导出仍能使用。服务端检查结束任务删除输入及画笔计划，主动删除或过期后回收结果。 |
| ☐ 比较、保存与导出 | 切换「原图／效果」放大核对印刷细节。未采用就退出时，原扫描页仍能编辑。保存图片后相册中的 JPG 与确认预览一致。允许「应用到扫描页」的样张，采用后再导出 JPG 和多页 PDF，逐页核对结果、方向和顺序。 |
| ☐ 既有功能 | 用同一批样张复测「擦除红蓝笔迹」、普通 OCR、裁切、加水印和 PDF 导出。切换试卷工具、取消或应用当前页时，其他页面保持原来的状态。 |

### 建议上线门槛

- **功能与保护。** 两端微信的逐项核对全部通过。出现未确认上传、马赛克暴露、保护笔失效、原页被覆盖、候选框错位或旧任务覆盖，就保留失败样张并修正后重测。
- **清理质量。** 可采用的最终结果中，印刷损失应为 0。辅助方案的可分离笔迹漏擦率建议不高于手动方案，且不超过样本目标笔迹的 5%。对同一区域的重复重试计入总耗时。
- **效率与资源。** 建议辅助方式的人工操作耗时中位数至少比配对手动减少 20%，总耗时中位数不增加。目标 VPS 在无排队时，普通提示和擦除预览的端到端 p95 各建议在 15 秒以内，DeepSeek 提示建议在 30 秒以内。记录高分辨率单页和连续任务的峰值内存、超时与恢复。任一辅助方式达不到门槛时，保留手动流程，并继续验证相应辅助功能。
- 这些数值是拟定的验收门槛，表格应填目标设备与目标 VPS 的实测数据。
