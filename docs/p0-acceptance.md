# 首版验收

## 样本

- 斜拍有边框的纸质表格，另拍一张白纸置于浅色桌面，检查找边和手动修正。
- 用台灯和手制造阴影，拍下同时包含浅色手写、标点、小字号文字和红色图案的测试纸。真实印章和个人资料可以用自制图案替代。
- 拍一张靠近书脊、文字行弯曲的单面书页，确保正文和页边均可见。
- 准备多张有明显编号的测试照片。在普通和较大页数下分别测试，记录试到的最大稳定页数和使用的清晰度设置。

## 验收表

这些项目应分别在 iOS 和安卓微信上执行，未覆盖的设备或系统记录为待测。

| 操作 | 通过条件 |
| --- | --- |
| 拍照，导入竖向和横向图片 | 前后方向一致，裁剪框与照片对齐。 |
| 对斜拍表格自动找边，拖动四角后确认 | 正文和表格边缘完整，文字行和表格线拉正。浅色桌面上找边失准时，可手动调整。 |
| 对浅阴影和散落斑点切换原色、灰度和黑白 | 预览可对照原图，浅色手写、标点和印章边缘仍可辨认。 |
| 添加、旋转、删除并重排多页，切断网络后导出 PDF | 页面数量、顺序和方向与列表一致，微信能打开生成的 PDF。导出失败时仍可返回编辑。 |
| 对靠近书脊的书页发起弯曲矫正 | 处理预览中的文字行更直，页边内容完整，可选择保留本地版本。 |
| 提交有深手影的页面 | 未选择的页面没有上传；输出亮度更均匀，小字依然易读。 |
| 上传中切断网络，或在任务处理中模拟超时 | 界面给出失败反馈，仍可继续编辑、导出本地页面。 |
| 在同一部手机上逐步增加导出页数 | 记录预览耗时、导出耗时、最大稳定页数和失败表现。 |

## 记录

- 构建提交号、微信预览工作流链接
- 手机型号、系统版本、微信版本
- 样本、页数、导出清晰度、状态、耗时
- 异常复现步骤和脱敏截图
- 真实 VPS 的单页耗时、峰值内存、是否完成故障恢复和临时文件清理
